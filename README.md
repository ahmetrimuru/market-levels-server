# Market Levels

Hisse kodu ve dönem seçildiğinde Yahoo Finance'ten fiyat geçmişini çeker, dönemin en yüksek ve en düşük fiyatına göre Fibonacci seviyelerini (%0, %23.6, %38.2, %50, %61.8, %78.6, %100) hesaplar.

## Çalıştırma

```
npm install
npm start
```

Tarayıcıda `http://localhost:3000` adresini açın. BIST hisseleri için sembolün sonuna `.IS` ekleyin (örn: `AKBNK.IS`).

## Uyarı

Bu araç yalnızca matematiksel fiyat seviyelerini gösterir; yatırım tavsiyesi değildir.
